# 06 中文书面语

论文的中文稿（中文摘要、中文对照稿、给导师看的中文文件）一律用书面语。标准不是“读得懂”，而是作者自己认可的文字（profile 里的“文风样本”）。请子代理复核中文稿时，也要拿作者的文字和批注作标准；只凭“读得懂”复核，口语化的问题常常会漏掉。

日常对话不适用本文件。

级别的写法见《01 包装》开头。程序 `scripts/register_scan.py` 能查出本文件里标了〔程序〕的几类。

---

**CN-01（必守）不写口语。** 被批为口语化、啰嗦的地方都属于这一类；改的时候在全部稿子里找同类（CMT-02）。

**CN-02（必守）不写括号里的解释。〔程序〕** 不写“（即……）”“（下称……）”“（如……）”这类说明性括号；需要的说明写进句子（“……，称为分段漂移模型”“……，其中‘分段’指温度按时段取不同的恒定值”），不需要的删去。保留：缩写首次出现时括号里的英文全称，如“剩余寿命（remaining useful life，RUL）”。全角、半角括号同样对待；程序只标出括号里有汉字的。

**CN-03（建议）不用“它”指代。〔程序〕** 写出所指的名词：该模型、该分布、该方法。

**CN-04（建议）回指用“该……”，不用“这一 + 名词”。〔程序〕** 例外：作者自己常用的固定说法，如“这一问题”“这一现象”（程序默认不标这两个）。

**CN-05（建议）不用口语和松散的说法。〔程序〕** 清单（左边不写，右边是可用的写法）：

| 不写 | 写成 |
|---|---|
| 能够……的，是…… | 直接陈述主语和谓语 |
| 所要实现的是…… | 直接陈述主语和谓语 |
| 越……越…… | ……随……的增大而增大（或减小） |
| 就是、也就是 | 即 |
| 读到 | 读取 |
| 改变不了、满足不了、学不会、得不到 | 无法改变、无法满足、无法学到、无法得到 |
| 不带误差 | 误差为零 |
| 合起来 | 共同、总 |
| 紧跟 | 紧随、跟随 |
| 只用 | 仅用、仅以 |

**CN-06（必守）不写工程腔。〔程序：只查固定说法〕** 例：“将两项损失直接相加”“把两组特征拼接后送入网络”。写成方法做什么、得到什么。

**CN-07（必守）不写绝对化的要求。〔程序：只查固定说法〕** 描述实际只是惩罚或偏好的做法时，不用“要求”“必须”去说模型；写成方法做什么、促使什么。方法确实施加硬约束时，照实写“约束……”（PACK-12）。

**CN-08（必守）每一步推理都写出理由。** 说“A 成为 B”时，写出为什么（例：`EX-CN-08`）。不单独写一个“转化为”。〔程序：只查单独的“转化为”〕

**CN-09（必守）一种模型只描述一遍。** 不先笼统地说一遍，再把各部分逐一重述。例：`EX-CN-09`。

**CN-10（必守）指代要明确，读者不用猜。** “其”“该”指谁不清时，直接写出所指的对象。例：`EX-CN-10`。

**CN-11（建议）用“我们”，不用“本研究”。**

**CN-12（必守）不逐词翻译英文。** 中文按中文的语序和习惯写，内容与英文逐句对应。

**CN-13（必守）一样东西一个词，全文统一。** 每篇论文的用词表在 profile 里。

**CN-14（必守）不在精确的定义之后，再用“即……”以宽泛的说法重述一遍。〔程序：只标候选〕** 删去的是重述。例：“该指标为预测寿命与真实寿命之差的平方的均值，即预测偏离真实的程度”，后半句应删去。定义和命名本身可以用“即”。放在例子之后、概括例子意思的“即……”也是重述：把概括移到例子之前，作为说明（见 ABS-05）。

**CN-15（必守）列举几条性质、理由或做法时，每一条写成：依据，由依据得到的结论，以及据此采取的做法，连接词写出来。** 不写省去因果的话题链：几个短语并列，依据、结论和做法之间没有“因而”“据此”这类连接。结论只对哪个对象、在什么条件下成立，写明。例：`EX-CN-15`。

## 改完自问

- **CN-Q1（自问）** 把作者认可的文字（文风样本）和这一段并排读，语气是否一致？
- **CN-Q2（自问）** 删掉一个括号，句子是否还完整？说明是否写进了句子？
- **CN-Q3（自问）** 这一段能否在不看英文的情况下读懂？
