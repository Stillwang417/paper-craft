# 05 科学化写法：不写成工程手册

级别的写法见《01 包装》开头。

---

**SCI-01（必守）论文要科学化，不写代码流程。** 从问题的形式化陈述出发；构造要点写成定义与命题（附证明），由要求推出；已有工作写成特例，或写明其不满足哪一条；实现细节（窗口、掩码、超参数、文件结构）只放附录或补充材料；改变命题前提的实现选择除外，按 SCI-04 写在命题所在的段落。

**SCI-02（必守）理论分析融进各组件的小节，不单独成“分析”一节。** 每个组件的小节：解决的问题 → 定义 → 说明设计为何成立的命题 → 由此得到的方法 → 实现细节见附录。成因类命题放在问题与成因一节，证明放附录。单独拆出的分析一节，读者难以把命题与对应的组件联系起来。

**SCI-03（必守）一串“必须满足的要求”写成由命题推出的性质。** 每条：性质 + 该性质成立或不成立时结果有何不同 + 出自命题的哪一部分。改标题不够，正文也要改（见 INNOV-06）。

**SCI-04（必守）命题的前提写在同一段里。** 例：实际实现只用最近 k 次循环的容量估计漂移系数时，写明；闭式结果只在温度恒定时成立时，写出该条件。合并、压缩时不让结论说过头。

**SCI-05（必守）不用远距离的序号指代（“第二项要求”），直接写内容。**

**SCI-06（必守）方法一节不放结果和常数。** 结果写在实验里；常数换成符号，数值放附录。

**SCI-07（必守）不写防御性句子；口气肯定、与证据相称（SCI-08）。限定随它所限定的主张出现，同一处不重复。**
- 删除：只为预先回应质疑、不推进论证的句子，以及同一处对同一主张的重复限定。同一主张在摘要、引言、贡献列表、结论中重述时，限定随之重述。
- 保留：界定主张范围的句子（如 we do not claim…）和读者理解结果所必需的事实披露（例如样本量小、数据只来自一种电池型号），各在所属位置写一次。
- 正文表格里没有测量的格子不写“未运行”；在表注里照实写明哪些格子没有测量及原因（例如该方法不适用于此设定，或该实验没有进行）。

**SCI-08（必守）结论强度不许悄悄升降。** 强度从弱到强：与……相当（差异无法区分）→ 点估计更优 → 差异的置信区间不含零，或经事先指定的检验显著 → 在独立的数据上重复成立 → 可推广、有实际价值。改写、压缩、翻译时，不能自己挪档；要挪档，必须有新的证据，并说明。这一梯子的思路参考了 academic-research-skills（Imbad0202）中 academic-paper skill 的结论强度分级（见 README 的致谢）。

**SCI-09（必守）保护限定语。** 每篇论文在 profile 里列出一份限定语清单（例：“在温度恒定的条件下”“在活化能为正的条件下”“在验证集上”）。保护限定语不删；压缩时先从别处删，实在删不了，告诉作者是哪一句限定语占了字数。

**SCI-10（必守）同一个量在方法、实验和附录里用同一个记号；记号首次出现时给出定义，一个记号只有一个含义。**

**SCI-11（必守）由一个命题得到几条结论时，写明每条出自命题的哪一部分，不笼统地写“由此得到”。** 例：“温度恒定时剩余寿命服从逆高斯分布”出自引理 1；“恒定温度下的平均剩余寿命随该温度的升高而缩短”由引理 1 的均值表达式与“活化能为正时漂移系数随温度单调增大”共同得到，两条的出处分别写明。

## 改完自问

- **SCI-Q1（自问）** 这一段删掉，论证还成立吗？成立就删，或缩成一句作为支撑。
- **SCI-Q2（自问）** 这一段读起来是“怎么做”，还是“为什么这样做、得到什么”？
