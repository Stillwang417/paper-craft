# 03 摘要

级别的写法见《01 包装》开头。数字上限只写在本篇论文的 profile 里，其他地方引用那里。

| 量 | 写在哪里 | 说明 |
|---|---|---|
| 英文摘要上限 | profile 的“投稿上限” | 以目标期刊现行的投稿指南为准；记下网址和查阅日期；没有直接读到官网时，写明出处，并请作者在自己的浏览器里核对 |
| 关键词个数 | 同上 | 不同来源说法不一致时，以官网为准 |
| 中文摘要 | — | 一般不设上限；与英文逐句对应 |

---

**ABS-01（必守）先写完整的长版，把思路逐层写清，再从长版中提取要点，压成短版。英文先写，中文随后，中文要读得顺。**

**ABS-02（必守）次序。** 应用领域一句 → 具体问题（先说明问题是什么，再举例）→ 研究现状（几类方法，各一个短语）→ 现有方法的缺陷（一句，必须有）→ “针对以上问题”：提出方法（给出英文全称）→ 几个创新点 → 结果（一到两个数字）→ 与证据相称的价值（一句）。

**ABS-03（必守）四个动作：问题；方法；一到两个带数字的关键结果；与证据相称的价值。** 动笔前先问：这是在吸引读者，还是在回答研究最终表明了什么？

**ABS-04（必守）第一句十来个词，直接点出领域和要解决的问题。**

**ABS-05（必守）举例之前先说明问题是什么。** 例句不能只是现象；例句的任务是解释问题，所以先写一句说明，再举例。

**ABS-06（必守）摘要要说出方法的名字和机制（约两句），不能写成流水账（定义 → 原因 → 组件 → 数字）。**
- （建议）先单独把摘要给作者看，再动其余部分。

**ABS-07（必守）现有方法各一个短语；缺陷一句。** 现有方法的描述必须与原文一致，不把我们自己的对照或设定归给别人；缺陷句只写现有方法确实存在的不足，不把现有方法没有用过的做法归给现有方法。

**ABS-08（必守）摘要（长版、短版）不用括号注释。** 不写“（即……）”“（下称……）”这类说明性括号；需要的说明写进句子，不需要的删去。细则见《06 中文书面语》CN-02。

**ABS-09（建议）删掉括号注释后，若某个术语在短版里没有交代，把交代写进句子；字数不够时，在交付时说明一次，附一句可直接替换的写法，不恢复括号注释。** 单位不清的数字必须改清（ABS-10），从别处让字。

**ABS-10（必守）结果句的数字与正文一致，单位正确。** 绝对量带单位；相对变化写明相对于什么；二者不混用。结果句报告绝对量还是相对变化，定稿前与正文统一。

**ABS-11（必守）压缩时不丢前提。** “在温度恒定的条件下”“在验证集上”这类保护限定语不删；放不下时，删减或合并主张本身，或告诉作者是哪一句限定语占了字数（SCI-09）；不以删去限定语来满足字数上限。限定语清单见 profile。

**ABS-12（必守）字数按程序数，改一次数一次。** 没数过不说“数过了”。达到上限时，每处改动都要字数持平。程序：`scripts/count_words.py`。

**ABS-13（建议）字数紧时，按下面的次序保留，越靠前越先保留。** 期刊上限 → 作者与导师已定的内容和改动 → 价值句 → 预留字数 → 术语交代与数据量。保护限定语不参与取舍（ABS-11）。字数不够时，可以去掉某个创新点的问题从句，直接写“首先，建立……”。

**ABS-14（必守）中英文逐句对应，中文按中文书面语写，不逐词翻译。** 中文版可以比英文多交代一点（中文一般不受字数限制），但不能说出英文没有的结论。

**ABS-15（必守）稿件文件与修改说明分开存放；发给导师或合作者的稿件里，不夹带修改过程中的说明。**

## 改完自问

- **ABS-Q1（自问）** 编辑只读第一句和最后一句，能否知道研究什么问题、结果如何？
- **ABS-Q2（自问）** 核心创新点的每个子点，是否都是我们实际做的工作？（见 PACK-02）
- **ABS-Q3（自问）** 每个数字都能在正文的表或段落里找到吗？
