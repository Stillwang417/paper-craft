# 04 引言、相关工作、题目与结论

级别的写法见《01 包装》开头。

---

## 引言

**INTRO-01（必守）结构：背景与需求 → N 个挑战 → 现有方法按类 → 方法 → 贡献。**
1. 背景与需求：重要性 → 痛点 → 需求；可以两条动机并行，汇到需求上。
2. N 个核心挑战，每个写成：现象 → 具体例子 → 根本原因 → 后果；配一张挑战图（图 1）。
3. 现有方法按类写，每类：做法 → 长处 → “但”缺陷；各类的缺陷汇成 N 个共同缺陷，与 N 个挑战一一对应。每个缺陷须由所引方法的原文支持，不为凑齐对应而把缺陷归给现有方法（INNOV-11）。
4. 方法：先总述，再写 N 个组件，每个组件回答一个挑战，最后是整体流程。
5. 贡献：框架、每个组件各一条、实验（带一个关键数字）。

**INTRO-02（必守）挑战、缺陷、组件、方法图分图的次序处处一致。** 写引言之前先列出这张对应表。

**INTRO-03（必守）引言不重复摘要的句子。** 引言补充证据、例子和与已有工作的比较。

**INTRO-04（建议）缺陷句不写“没有一类……没有一类……没有一类……”。** 每个空白都归到写出了相应“但”缺陷的那一类方法上，并且要由该类方法句中已写明的缺陷推出。

**INTRO-05（建议）根本原因写的是基线自身的机制，不是我们方法的局限。**

**INTRO-06（建议）在所属小节之前就用到的术语，第一次出现时就说明其含义。** 同 TERM-04。

**INTRO-07（必守）写清任务是什么。** 例如做的是在线预测，图和文字就都要表现预测随新的测量逐次更新，不让读者以为做的是一次性的离线拟合。

**INTRO-08（建议）基线的叫法固定。** 各篇的叫法记在 profile 的用词表里。

## 相关工作

**INTRO-09（必守）相关工作几行一层、逐步收窄，次序服务于方法上的选择（任务 → 骨干 → 训练方法）。**
- （必守）与本文相近的已有工作，在引入相应对象的地方引用；相关工作中写明区别。

## 题目

**INTRO-10（必守）题目说出方法和方法的作用，例如 X for Y，或方法名加冒号、再说方法是什么。** 题目写性质时只写命题给出的，前提放不进题目时，题目不写该性质（PACK-15）。题目不写成对问题的分析。

## 结论

**CONC-01（必守）结论三步：围绕研究问题把发现连成一段叙述（不是一串数字）；说出证据支持的判断和新的认识；划出边界：未解决的问题、研究的局限、下一步。**

**CONC-02（必守）局限集中写在一段，写必要的披露；不在全文各处重复。** 主张自带的限定照常随主张出现（SCI-07）。

## 改完自问

- **INTRO-Q1（自问）** 读者在方法的每一部分，能否说出这一部分回答的是哪一个挑战？
- **INTRO-Q2（自问）** 引言里有没有哪一句是从摘要里搬来的？
